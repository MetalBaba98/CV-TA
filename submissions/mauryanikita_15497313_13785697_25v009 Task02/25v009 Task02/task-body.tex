\begin{studentSpace}
    The bicycle was detected using a pretrained YOLOv8n object detection model from the Ultralytics framework. The model was trained on the COCO dataset, in which the bicycle category corresponds to class ID 1. 
    Initially, the image was processed using the default YOLOv8n inference settings. However, the bicycle is located far from the camera and occupies only a small number of pixels in the image. As a result, the 
    default inference resolution failed to detect the bicycle. To improve detection performance, the inference image size was increased to 1280 pixels and the confidence threshold was reduced to 0.05. These changes 
    preserved more visual detail for small objects and allowed the bicycle to be detected successfully.

    The bounding box produced by YOLO encloses the entire bicycle. However, projective geometry calculations require a single point that represents the bicycle's location on the ground plane. 
    Several candidate points can be selected from the bounding box. For this assignment, the bottom-center of the bounding box was selected because it best approximates the point at which the bicycle touches the road surface.
    The choice of reference point from bounding box affects the accuracy of distance estimation. This can be seen as the bounding box coordinates varies -
    Top-left : (1110,2078)
    Bottom-right : (1194,2136)
    The bounding box height is approximately 58 pixels. Choosing the center of the bounding box instead of bottom-center shifts the reference point upward by 25-30 px, which changes estimated distance roughly by 5-10 metres. 
    
\end{studentSpace}
